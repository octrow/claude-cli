# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/octrow/claude-cli/security/advisories/new).
You should get a reply within a week.

## Supported versions

Only the latest release gets fixes.

## Scope

In scope: problems in this library's code, for example leaking prompts or credentials into logs or the cache, or unsafe subprocess handling. Out of scope: vulnerabilities in the Claude Code CLI or in OmniRoute themselves; report those to their maintainers.
